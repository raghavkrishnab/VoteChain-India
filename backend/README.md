# Backend

Express 5 API on port 5000 with MongoDB Atlas. See [docs/api.md](../docs/api.md) for the endpoints.

```powershell
npm run dev                       # start with file watching
npm test                          # API tests (no database needed)
npm run seed:admin                # create/update the admin user from .env
npm run reset:elections -- --yes  # wipe elections/candidates/votes after redeploying the contract
```

`src/services/chain.js` reads the contract over `BLOCKCHAIN_RPC_URL`. Its ABI (`src/config/contractAbi.json`) is generated by `npm run sync-abi` in `blockchain/`.
